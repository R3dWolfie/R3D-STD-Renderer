# Modern hit-error meter icons

Canonical TheAussie HEM icons, copied byte-for-byte from the current R3D
Mania implementation at commit 78ff3b8. The Mania fidelity report traces these
to the owner website assets in `public/assets/osu/hud/hit-error-meter/`; their
SHA-256 values match that source too. `provenance.json` records exact paths,
commit and hashes. Both PNGs are 100×100 grayscale/alpha. Runtime conversion
to RGBA and contain-fit preserve the original aspect ratio.

The source renderer is AGPL-3.0-or-later, as is this renderer. No distinct
asset-specific licence or author notice accompanies these supplied icons;
this port retains the source bytes and attribution rather than inventing
a different asset licence. They are included at the owner's explicit request.
